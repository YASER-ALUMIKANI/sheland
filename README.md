## 🌟 أبرز الميزات والأنظمة

### 🛒 الواجهة الأمامية والمتجر الرئيسي (`frontend/index.html`)
- **تصميم استثنائي وعصري:** أنماط تصميمية حديثة (Glassmorphism، ألوان Tailwind Tailored، خط Inter & Cairo، ودعم النمط الداكن).
- **تجربة الشراء الفورية بضغطة زر:** إمكانية الشراء المباشر عبر زر **⚡ اشترِ الآن** دون تعقيد.
- **تطبيق الكوبونات المباشر:** إدخال وتطبيق أكواد الخصم في درج السلة (Cart Drawer) وفي نافذة الشراء الشاملة (Checkout Modal).
- **المراجعات الحقيقية بالصور:** نظام تقييمات موثقة بالنجوم وإرفاق الصور الحقيقية وشارة "مشتري مؤكد" (`Verified Buyer`).
- **التتبع المباشر عبر الواتساب:** إرسال إشعارات وتفاصيل الطلبات عبر الواتساب بنقرة واحدة.

### 🛡️ لوحة التحكم والإدارة الإستراتيجية (`frontend/admin.html`)
- **إدارة المنتجات والكتالوج الشامل:** إضافة، تعديل، استيراد وتصدير المنتجات عبر Excel.
- **إدارة التصنيفات وطرق الدفع:** التحكم الكامل في طرق الدفع الإلكتروني (الكريمي، وان كاش، جوالي، فلوسك، والدفع عند الاستلام).
- **🎟️ إدارة الكوبونات وقسائم الخصم:** إنشاء كوبونات جديدة بنسب مئوية أو مبالغ ثابتة مع تحديد الحد الأدنى وحذفها نهائياً.
- **📊 مركز المثلث الذهبي لمؤشرات الأداء (KPIs Center):** حساب معدل التحويل (CR)، متوسط قيمة السلة (AOV)، وتكرار الشراء (Repeat Rate) تلقائياً.
- **🚨 مركز تنبيهات المخزون والركود:** تتبع التنبيهات الفورية للمنتجات التي أوشكت على النفاذ (≤ 5 قطع) والمنتجات الراكدة لأكثر من 7 أو 30 يوماً.
- **🧾 تصدير التقارير والفواتير (Excel & PDF):** تصدير تقارير المبيعات الأسبوعية والشهريّة بصيغة `.xlsx` منسقة، وإصدار الفواتير الرسمية المطبوعة بشعار المتجر كـ PDF.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الخادم الخلفي (Backend):** Python 3.10+ | FastAPI | SQLAlchemy ORM | Pydantic v2 | Uvicorn
- **قاعدة البيانات (Database):** SQLite (مع حماية SQLite Shared Cache للمستويات العالية وسهولة النقل)
- **الواجهة الأمامية (Frontend):** Vanilla HTML5 | Custom CSS3 (Tokens System) | JavaScript (ES6+)
- **الأمان والتحقق (Security):** JWT Tokens (PyJWT) | Passlib (Bcrypt) | Rate Limiting (SlowAPI)
- **المعالجة والتقارير (Reports):** `openpyxl` لملفات الإكسل المنسقة | Native CSS Print & PDF Formatters
- **حزمة الاختبارات (Testing):** Pytest | TestClient

## 🔐 الحماية وصلاحيات الوصول (Security & RBAC)

تتضمن المنصة نظام حماية متكامل ومبني على الأدوار (`Role-Based Access Control - RBAC`):
1. **المدير الشامل (`admin` / `super_admin`):** الوصول الكامل لكافة الأقسام، المبيعات، الفواتير، الكوبونات، والمؤشرات.
2. **مدير المبيعات (`sales_manager`):** التحكم في الطلبات والكوبونات والتقارير.
3. **البائع / التاجر (`seller`):** إضافة المنتجات وتحديث مخزونها ومتابعة المبيعات الخاصة به.
4. **العميل (`customer`):** التصفح، الشراء، استخدام الكوبونات، كتابة المراجعات، وتتبع الطلبات.

## 🎟️ نظام الكوبونات وقسائم الخصم

- **أنواع الخصم:** نسبة مئوية (مثال: `10%`) أو مبلغ ثابت (مثال: `1000 ر.ي`).
- **الشروط:** إمكانية تحديد الحد الأدنى للطلب لتفعيل الكوبون.
- **التطبيق الفوري:** يتم احتساب الخصم تلقائياً وتحديث الإجمالي في السلة وفي نافذة الدفع وفي الفاتورة المطبوعة.
- **الـ Endpoints الخاصة بالتأكيد والتحقق:**
  - `GET /api/coupons`: عرض الكوبونات.
  - `GET /api/coupons/validate?code=...&total=...`: التحقق من صحة الكوبون وقيمته.
  - `POST /api/coupons`: إنشاء كوبون جديد (للأدمن).
  - `DELETE /api/coupons/{id}`: حذف كود الخصم.

## 🚨 نظام إدارة المخزون والتنبيه بالنفاذ والركود

1. **تنبيهات المخزون المنخفض (Low Stock Alerts):**
   - تنبيه آلي عند انخفاض كمية أي منتج إلى **5 قطع أو أقل (≤ 5)**.
2. **تنبيهات المخزون الراكد (Stagnant Stock Alerts):**
   - **الراكد أسبوعياً:** المنتجات المتوفرة بمخزون والتي لم تُسجّل أي حركة مبيعات لأكثر من **7 أيام**.
   - **الراكد شهرياً:** المنتجات المتوفرة بمخزون والتي لم تُسجّل أي حركة مبيعات لأكثر من **30 يوماً**.
3. **تنبيه البائع الفوري:** إمكانية إرسال رسالة واتساب بنقرة واحدة إلى هاتف البائع لتزويد المخزون أو عمل تنزيلات على المنتج الراكد.

## 🚀 التثبيت والتشغيل المحلّي (Setup & Installation)

### 1. استنساخ المشروع وتجهيز البيئة:
```bash
cd f:\CityLand
python -m venv venv
# On Windows:
venv\Scripts\activate
```

### 2. تثبيت الحزم المتطلبة:
```bash
pip install -r requirements.txt
```

### 3. تشغيل الخادم الخلفي (FastAPI Server):
```bash
python -m uvicorn backend.main:app --reload --port 8000
```

- **رابط المتجر:** `http://127.0.0.1:8000`
- **لوحة تحكم الأدمن:** `http://127.0.0.1:8000/admin`
- **وثائق الـ API التفاعلية (Swagger UI):** `http://127.0.0.1:8000/docs`
