# 🛍️ Sheland Marketplace (منصة سوق شي لاند الإلكتروني)

سوق إلكتروني شامل ومتقدم بأسعار منخفضة جداً ومصمم بآلية الـ Micro-Marketplace المستوحاة من نماذج التجارة الحديثة (مثل Meesho)، مع دعم الشحن والتوصيل المباشر إلى **مدينة البيضاء** وكافة المحافظات اليمنية والعملة بالريال اليمني (`ر.ي / YER`).

---

## 🌟 أبرز المميزات والإمكانيات

- **🎨 تصميم متجاوب وهيكلية فائقة (Vanilla HTML/CSS/JS):** واجهة سريعة وخفيفة بالكامل دون تعقيدات وبدعم مخصص للهواتف المحمولة والنمط الداكن (Dark Mode).
- **⚡ خادم خلفي عالي الأداء (FastAPI + SQLAlchemy + Pydantic):** بناء محكم ومستقل بنسبة 100% يتبع معايير النظافة والسرعة.
- **🏷️ شريط فلاتر Meesho والحبوب الدائرية:** تنقل فوري بضغطة زر بين الفئات والأقسام الأكثر صلة.
- **🏬 شريحة المورد الموثوق (M-Trusted Supplier):** إظهار بيانات وتقييم البائع وضمان الإرجاع خلال 7 أيام.
- **💬 الطلب والاتصال المباشر عبر الواتساب:** زر اطلب الآن عبر الواتساب مجهز بتفاصيل المنتج والبيانات تلقائياً.
- **⚠️ تنبيهات وإدارة المخزون:** كروت ولوحة تحكم حية لإدارة وتنبيه المخزون المنخفض.
- **🎟️ نظام الكوبونات والخصومات:** دعم الأكواد الترويجية مثل `CITY10` و `SAVE20` مع احتساب فوري.
- **📍 تتبع الطلبات والمراحل:** نظام تتبع مرئي بالخط الزمني للشحنة.
- **🔐 حماية وأمان (Security Audited):** حماية كاملة ضد ثغرات XSS و SQL Injection وحماية الـ Admin بكلمة مرور.
- **🧪 اختبارات آلية 100%:** حزمة اختبارات متكاملة تغطي كافة نقاط الـ REST APIs بنسبة نجاح 100%.

│   ├── index.html            # المتجر والسوق الرئيسي

## 🚀 تشغيل المشروع محلياً (Local Development)

### 1. تشغيل الـ Backend والسيرفر:
```bash
python -m uvicorn backend.main:app --port 8000
```
- **المتجر الرئيسي:** `http://127.0.0.1:8000`
- **لوحة تحكم الأدمن:** `http://127.0.0.1:8000/admin` (كلمة المرور الافتراضية: `admin123`)
- **توثيق الـ API الفوري (Swagger UI):** `http://127.0.0.1:8000/docs`

## 🧪 تشغيل حزمة الاختبارات الآلية (Automated Testing)

لتشغيل الاختبارات والتحقق من سلامة كافة الـ APIs:
```bash
python -m pytest backend/tests/test_api.py
```
**النتيجة المتوقعة:** `8 passed in 0.75s` (نجاح بنسبة 100%).

## 🐳 النشر الفوري للإنتاج عبر Docker (Production Deployment)

لتشغيل المشروع في بيئة الإنتاج بضغطة زر واحدة:
```bash
docker-compose up -d --build
```

سيتم تشغيل وتجميع التطبيق وخادم الـ Web وتغذية البيانات تلقائياً وتجهيز الفحص الصحي (Healthcheck).
